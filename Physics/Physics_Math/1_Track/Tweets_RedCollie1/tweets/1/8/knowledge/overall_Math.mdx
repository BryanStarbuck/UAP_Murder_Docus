**sin(θ) = v/c**

Then:
**cos(θ) = √(1 - v²/c²) = 1/γ** (the inverse Lorentz factor)

**tan(θ) = v/c · γ = βγ** (the relativistic momentum parameter)

The standard Lorentz transformation in Minkowski space using the rapidity η (where tanh(η) = v/c):
- x' = x cosh(η) - ct sinh(η)  
- ct' = -x sinh(η) + ct cosh(η)

Using Drew's angle θ instead, with sin(θ) = v/c:
- cosh(η) = γ = 1/cos(θ)
- sinh(η) = βγ = tan(θ)

The Lorentz transformation becomes:
- **x' = x/cos(θ) - ct·tan(θ) = (x - v·t)/cos(θ) · cos(θ) = (x - vt)·γ**
- **ct' = -x·tan(θ) + ct/cos(θ) = γ(ct - βx)**

Which is the standard form, confirming the parametrization is consistent.

**De Broglie connection:**
The de Broglie relation: λ = h/p = h/(mγv)

Substituting γ = 1/cos(θ) and v = c·sin(θ):
**λ = h·cos(θ)/(m·c·sin(θ)) = (ℏ/mc) · (2π·cos(θ)/sin(θ)) = λ_Compton · cot(θ)/2π**

where λ_Compton = h/(mc) is the Compton wavelength.

For small θ (non-relativistic limit): cot(θ) → 1/θ ≈ c/v, giving λ ≈ h/(mv) — the classical de Broglie formula.
