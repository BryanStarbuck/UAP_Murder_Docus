## 6. Galois Field GF(4) Quaternary Logic

Source tweet: 1979690150704922939:
"Use 4 symbols, and the random XOR function, to develop a new and infinitely better type of encryption."

GF(4) has characteristic 2, defined by irreducible polynomial p(x) = x^2 + x + 1 over GF(2).
Elements: {0, 1, alpha, alpha^2 = alpha+1} where alpha is a primitive element.

Addition in GF(4) (= XOR for quaternary symbols):
0 + 0 = 0, 0 + 1 = 1, 0 + alpha = alpha, 0 + (alpha+1) = alpha+1
1 + 1 = 0, 1 + alpha = alpha+1, 1 + (alpha+1) = alpha
alpha + alpha = 0, alpha + (alpha+1) = 1
(alpha+1) + (alpha+1) = 0

Multiplication in GF(4):
0*x = 0 for all x; 1*x = x for all x
alpha * alpha = alpha+1; alpha * (alpha+1) = 1; (alpha+1)*(alpha+1) = alpha

Shannon entropy of a quaternary source: H = -sum_{i=0}^{3} p_i * log_2(p_i) bits/symbol.
For uniform distribution: H = log_2(4) = 2 bits/symbol.

Information density ratio vs. binary: each quaternary symbol carries exactly 2 bits of information (compared to 1 bit/symbol for binary). For a block cipher with N-symbol blocks: quaternary block has N*log_2(4) = 2N bits of information, vs. N bits for binary block of same symbol count. Brute-force key search space: 4^N vs. 2^N — exponentially larger for quaternary.
