### 2. Lorentz Torque on Homopolar/Corbino Disc

XY-plane force density (body force per unit volume):
f = J × B  (N/m³)

where J (A/m²) is the radial current density and B = B_z ẑ is the axial field.

For J = J_r r̂:
f = J_r B_z (r̂ × ẑ) = -J_r B_z φ̂

Torque on annular disc (inner radius R₁, outer radius R₂, thickness h):
τ = ∫∫∫ r × f dV

In cylindrical coordinates, the azimuthal force density produces torque:
dτ = r × (-J_r B_z φ̂) r dr dφ dz

τ_z = ∫₀ʰ dz ∫₀²π dφ ∫_{R₁}^{R₂} r J_r B_z r dr

τ_z = 2π h J_r B_z ∫_{R₁}^{R₂} r² dr = 2π h J_r B_z (R₂³ - R₁³)/3

If total radial current I = J_r × 2πr h (for radially uniform current density):
J_r = I/(2πrh)

Then:
τ_z = 2π h B_z ∫_{R₁}^{R₂} [I/(2πrh)] r² dr = I B_z ∫_{R₁}^{R₂} r dr = I B_z (R₂² - R₁²)/2

This is the standard homopolar motor torque formula. Increasing I, B_z, or (R₂² - R₁²) increases the XY-plane driving torque.

### 5. Magnetic Mirror Force (Ion Acceleration)

Mirror force along z-axis:
F_z = -μ ∂B/∂z

For the "faucet of magnets" geometry with alternating poles creating gradient regions:
If B decreases along z: ∂B/∂z < 0 → F_z > 0 (ions accelerated in +z direction)
If B increases along z: ∂B/∂z > 0 → F_z < 0 (ions decelerated / reflected)

### 6. Counter-Spin Angular Momentum Balance

System angular momentum:
L_total = L_1 + L_2

L_1 = I_1 ω_1 ẑ  (central magnet, spinning at ω_1 in +z direction)
L_2 = I_2 ω_2 ẑ  (outer flywheel, spinning at ω_2 in -z direction, so ω_2 < 0)

For zero net angular momentum:
I_1 ω_1 + I_2 ω_2 = 0
⟹ I_2 |ω_2| = I_1 ω_1
⟹ |ω_2| = (I_1/I_2) ω_1

If I_2 < I_1 (lighter outer flywheel), then |ω_2| > ω_1 — the outer flywheel must spin faster to compensate for lower moment of inertia. This determines the gear ratio between the two power supplies.

Alternatively, if the goal is not zero total L but a specific value L_target (to produce a specific precession rate under the 3-phase field):
Ω_prec = τ / L_target = τ / (I_1 ω_1 + I_2 ω_2)

This provides a tuning parameter for the Z-axis force by adjusting either ω_2 or the field coupling τ.

### 10. Precession Rate Dependence on Spin Speed

For the levitation mechanism, if the Z-axis force F_z is proportional to the precession rate Ω_prec:

F_z = k Ω_prec = k τ / L = k τ / (I ω_spin)

Then: F_z ∝ 1/ω_spin

This counterintuitive result (faster spin → less lift) would follow if the mechanism is precession-rate-dependent rather than angular-momentum-dependent. However, the torque τ from the 3-phase field is itself a function of ω_spin (through the interaction of the rotating field with the spinning magnet — essentially a synchronous motor coupling), making the relationship:

τ(ω_spin) = f(ω_field, ω_spin, coupling constants)

At synchronous speed (ω_spin = ω_field), τ → 0 in the classical case, producing zero precession and zero lift. Off synchronous speed, slip produces torque, precession, and potentially lift. The optimal operating point has not been specified in Drew's work — representing the key experimental parameter space.
