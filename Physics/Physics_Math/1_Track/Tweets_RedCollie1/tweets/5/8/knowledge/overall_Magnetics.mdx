- Center terminal: positive (+); rim terminal: negative (−).

**Motional EMF derivation** (from image label and standard physics):

The motional EMF for an infinitesimal segment d**l** along the spoke is:
```
dε = (**v** × **B**) · d**l**
```
With **v** = ωr φ̂ (tangential), **B** = −B ẑ (into page), d**l** = dr r̂ (radial):
```
(**v** × **B**) = ωr φ̂ × (−B ẑ) = −ωrB (φ̂ × ẑ) = −ωrB (−r̂) = ωrB r̂
```
Therefore:
```
dε = ωrB dr
```
Integrating from r = 0 to r = R:
```
ε = ∫₀ᴿ ωrB dr = ωB R²/2
```

**Total EMF**: ε = ωBR²/2

This is DC without a commutator. Current flows radially from center to rim (or rim to center depending on field/rotation orientation). The homopolar motor (run as a motor rather than generator) produces an azimuthal (tangential) Lorentz force **F** = I (**dl** × **B**) on radial current elements, generating continuous torque without brush switching.

**Corbino disc**: A variant of the homopolar disk where the conductor is an annular disk (inner radius r₁, outer radius r₂). The geometry produces current concentration at the inner radius and relevant eddy-current suppression at the outer radius.

```
B_inner(t) = B₀[cos(ωt) x̂ + sin(ωt) ŷ]   (right-handed rotation)
```

This is a linearly oscillating field, not a rotating one — the rotating character is destroyed. **Enhanced repulsion via counter-rotation**:

If a drive motor spins the aluminum disc in one direction (+ω_Al), and the N-S-N-S-N-S magnet array counter-spins in the opposite direction (−ω_mag), then the **relative angular velocity** between the two is:
```
ω_rel = ω_Al + ω_mag   (magnitudes add because opposite directions)
```
The rate of change of flux through the aluminum disc scales with ω_rel. Since the induced EMF and hence eddy currents scale with dΦ/dt ∝ ω_rel, and the repulsive force scales with (eddy current)², the repulsion force scales approximately as:
```
F_repulsion ∝ ω_rel² = (ω_Al + ω_mag)²
```
This is substantially larger than either F ∝ ω_Al² or F ∝ ω_mag² alone, giving "greatly enhanced repulsions due to fast RELATIVE motions."
