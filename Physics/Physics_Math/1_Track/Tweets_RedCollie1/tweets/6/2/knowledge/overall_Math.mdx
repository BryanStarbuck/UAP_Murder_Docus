## Section: 1913486821096325413.yaml / 1922285721777307749.yaml — Magnet Geometry and Force Mathematics

### 3-Phase Rotating Field Vector

For three stator coils at 120-degree angular offsets, driven by balanced 3-phase AC at angular frequency ω:
```
B_x(t) = B_0 cos(ωt)
B_y(t) = B_0 cos(ωt − 2π/3)
B_z_stator(t) = B_0 cos(ωt − 4π/3)
```
Resultant field magnitude: |B_rot| = (3/2)B_0 = constant

The resultant field vector sweeps the XY-plane at angular velocity ω with constant magnitude — a pure rotating vector (circular polarization of the magnetic field).

### Magnetic Dipole Moment of Disk Magnet

For Nd₂Fe₁₄B disk magnet of radius r, thickness h, saturation magnetization M_s ≈ 1.28 × 10⁶ A/m:
```
m_d = M_s × V = M_s × π r² h    [A·m²]
```

Material properties (Nd₂Fe₁₄B):
```
(BH)_max ≈ 400–500 kJ/m³
B_remanence (B_r) ≈ 1.0–1.4 T
H_coercive (H_c) ≈ 750–2000 kA/m
μ_0 = 4π × 10⁻⁷ H/m
```

### Axial Dipole-Dipole Force (Z-axis)

Two co-axial magnetic dipoles m_1 and m_2 separated by distance d:
```
F_z = (3 μ_0 m_1 m_2) / (2π d⁴)
```
This is the far-field (d >> r) approximation. For near-field interactions (d ~ r), higher multipole terms contribute.

**Scaling law derivation:**
For geometrically similar magnets with fixed aspect ratio (h/r = const), volume V ∝ r³, so m_d ∝ r³:
```
F_z ∝ m_1 × m_2 / d⁴ ∝ r³ × r³ / d⁴ = r⁶/d⁴
```
For fixed d, F_z ∝ r⁶. Going from r = 20 mm (40 mm disk) to r = 30 mm (60 mm disk):
```
F_ratio = (30/20)⁶ = 1.5⁶ = 11.39
```
At the same separation d, the 60 mm magnet exerts approximately 11× greater force than the 40 mm magnet — explaining Drew's experimental observation of dramatically greater force with the 60 mm configuration.

### Moment of Inertia for Disk Magnet (Spin Optimization)

For a uniform cylindrical disk (mass m, radius r, thickness h):
```
I_z = (1/2) m r²
```
For material density ρ_Nd = 7400 kg/m³:
```
m = ρ π r² h
I_z = (π ρ h r⁴) / 2
```
For fixed mass m (fixed r, h product), reducing h (thinner disk at larger r) lowers I_z since I_z ∝ r² but m = ρπr²h means r² h = m/(ρπ) = const, so:
```
I_z = (1/2)(m)(r²) = (m²)/(2 ρ π h)
```
I_z decreases as h decreases (thinner disk) for fixed mass. Confirms preference for thin disks for high-ω (rapid spin) applications.

## Section: 1952829920469762104.yaml — Gyroscope Precession Equations

### Euler's Equations for Rigid Body Rotation

The general Euler equations for torque-free rotation of a symmetric gyroscope (I_1 = I_2 = I_perp, I_3 = I_spin):
```
I_perp (dω_1/dt) − (I_perp − I_spin) ω_2 ω_3 = 0
I_perp (dω_2/dt) + (I_perp − I_spin) ω_1 ω_3 = 0
I_spin (dω_3/dt) = 0
```
ω_3 = Ω = const (spin rate about symmetry axis). The body frame oscillates at the body-frame nutation frequency:
```
ω_body = ((I_spin − I_perp)/I_perp) Ω
```

### Torque-Driven Precession

With applied torque τ from 3-phase magnetic field:
```
dL/dt = τ_external
L = I_spin Ω ẑ_spin
Ω_precession = |τ| / (|L| sin θ) = τ / (I_spin Ω sin θ)
```
Precession angular velocity (steady-state, small nutation approximation):
```
Ω_p = τ_⊥ / (I_spin Ω)
```
where τ_⊥ is the component of applied torque perpendicular to the spin axis.

### Direction of Precession

Precession axis lies along τ × L:
```
Ω_p_hat = (τ × L) / |τ × L|
```
For a 3-phase magnetic torque that can be steered in the XY-plane by adjusting phase/amplitude, τ can point in any azimuthal direction, allowing Ω_p to be steered freely — providing full azimuthal attitude control.

## Section: 1978543995153195424.yaml — Lorentz and Homopolar Motor Equations

### Homopolar Motor EMF (Lorentz Spin)

Conducting disk radius R, rotating at angular velocity ω in uniform axial field B_z:
```
EMF = ∫₀ᴿ (v × B) · dr = ∫₀ᴿ (ω r B_z) dr = (1/2) ω B_z R²
```
For external circuit resistance R_ext, the radial current:
```
I = EMF / R_ext = ω B_z R² / (2 R_ext)
```
Torque on disk from this current in field B_z:
```
τ_motor = ∫₀ᴿ I B_z r dr = I B_z R²/2 = (ω B_z² R⁴) / (4 R_ext)
```
Power:
```
P = τ_motor × ω = (ω² B_z² R⁴) / (4 R_ext)
```
The homopolar drive torque scales as ω² B_z² R⁴, so increasing B_z (stronger magnets) or R (larger rotor) gives large gains.

### Magnetic Gradient Force (3-Phase Uplift)

Net Z-axis force on magnetic dipole m_z in non-uniform B field:
```
F_z = m_z (∂B_z/∂z)
```
For the force to be upward (levitating): need ∂B_z/∂z < 0 (field decreasing upward) with m_z > 0 (dipole aligned with field). Or ∂B_z/∂z > 0 with m_z < 0 (anti-aligned). The 3-phase stator geometry above the coil plane produces a specific ∂B_z/∂z profile that Drew claims is sufficient for levitation.

Equilibrium condition:
```
m_z (∂B_z/∂z)|_{z=z_eq} = Mg
```
This fixes the equilibrium height z_eq. Stability requires:
```
∂/∂z [m_z (∂B_z/∂z)] < 0   at z = z_eq
```
i.e., the gradient force must decrease as z increases above equilibrium (restoring condition — Earnshaw's theorem applies to static fields, but a rotating field effectively circumvents Earnshaw's theorem through time-averaging).

## Section: 2037284590776426579.yaml — Rotating Field Compass Dynamics

### Compass Needle Dynamics in Rotating Field

Compass needle as a damped magnetic pendulum in rotating field B_rot(t) = B_0 (cos(ωt), sin(ωt), 0):

Equation of motion for needle angle φ(t):
```
I_needle φ̈ + b φ̇ + m_needle B_0 sin(φ − ωt) = 0
```
where I_needle is needle moment of inertia, b is damping coefficient (air friction + pivot friction), m_needle is needle magnetic moment.

**Locked-rotation steady state:** If ω >> ω_0 = √(m_needle B_0 / I_needle), the needle cannot track the field. Instead it exhibits frequency-locked rotation at approximately ω with a phase lag determined by the balance between the driving torque and damping:
```
b ω ≈ m_needle B_0 sin(δ_phase)
δ_phase = arcsin(b ω / (m_needle B_0))
```
For b ω < m_needle B_0 (low damping, high field): continuous synchronous rotation.
For b ω > m_needle B_0: rotation stalls, needle oscillates erratically.

The observed continuous spinning of compass needles near UAPs is consistent with: strong rotating magnetic field, B_0 sufficiently large that b ω / (m_needle B_0) < 1, at frequencies in the range where ω >> ω_0_natural.

## Section: 2031137936574656726.yaml — Counter-Rotation Angular Momentum Algebra

### Dual Counter-Rotating Flywheel Angular Momentum

Flywheel 1: moment of inertia I_1, spin rate ω_1, angular momentum L_1 = I_1 ω_1 ẑ
Flywheel 2: moment of inertia I_2, spin rate ω_2, angular momentum L_2 = −I_2 ω_2 ẑ

Total angular momentum:
```
L_total = (I_1 ω_1 − I_2 ω_2) ẑ
```
Zero angular momentum condition:
```
I_1 ω_1 = I_2 ω_2
```
Under this condition, the system can change orientation without gyroscopic reaction torques on the vehicle frame. The vehicle body can be reoriented without the spinning rotors transferring gyroscopic torques to the airframe.

**Kinetic energy of counter-rotating system:**
```
KE = (1/2) I_1 ω_1² + (1/2) I_2 ω_2²
```
Even when L_total = 0, KE > 0. The kinetic energy stored in the counter-rotating flywheels is available to do work (e.g., drive magnetic propulsion) without violating L_total = 0 constraint.

**Gyroscopic stiffness under perturbation:**
For a small external torque τ_ext applied to the system with L_total = 0:
```
dL_total/dt = τ_ext → L_total(t) = τ_ext t
```
The system responds by accumulating angular momentum — no gyroscopic resistance to the first perturbation, but unlike a pure L_total = 0 system, the internal spinning components do exhibit rigidity relative to each other.
