### Lorentz Force Body Force Density — MHD Actuation of Liquid Metal

The force per unit volume on a current-carrying conducting fluid in a magnetic field:

```
f = J × B        [N/m³]
```

where:
- **J** = current density vector [A/m²]
- **B** = magnetic flux density vector [T]

For DC current J_r in radial direction r̂ and axial field B₀ = B₀ ẑ from disc magnet:

```
f_φ = J_r × B₀  (r̂ × ẑ) = −J_r B₀  φ̂        [N/m³ azimuthal]
```

Total azimuthal torque on liquid metal annulus (inner radius a, outer radius b, height h):

```
τ_φ = ∫∫∫ r · f_φ dV = ∫_a^b ∫_0^{2π} ∫_0^h r · (J_r B₀) r dr dφ dz
```

For uniform J_r and B₀:

```
τ_φ = 2π h B₀ J_r ∫_a^b r² dr = 2π h B₀ J_r (b³ - a³)/3
```

### 3-Phase Rotating Magnetic Field — Symmetrical Components

For a balanced 3-phase system (phases U, V, W) with phase separation 120° = 2π/3 rad, the instantaneous field contributions from each phase at a point P in the stator bore (single pole-pair approximation):

```
B_U(t) = B₀ cos(ωt) ê_U
B_V(t) = B₀ cos(ωt − 2π/3) ê_V
B_W(t) = B₀ cos(ωt − 4π/3) ê_W
```

where ê_U, ê_V, ê_W are unit vectors separated by 120° in the XY-plane:
```
ê_U = x̂
ê_V = −(1/2)x̂ + (√3/2)ŷ
ê_W = −(1/2)x̂ − (√3/2)ŷ
```

Superposition:
```
B_x(t) = B₀[cos(ωt) − (1/2)cos(ωt − 2π/3) − (1/2)cos(ωt − 4π/3)]
B_y(t) = B₀[(√3/2)cos(ωt − 2π/3) − (√3/2)cos(ωt − 4π/3)]
```

Simplifying using sum-to-product identities:

```
B_x(t) = (3/2)B₀ cos(ωt)
B_y(t) = (3/2)B₀ sin(ωt)
```

Magnitude:
```
|B_rotating(t)| = (3/2)B₀ = constant        [T]
```

Phase angle:
```
θ(t) = ωt        [rad]
```

This is a constant-amplitude field vector rotating in the XY-plane at angular frequency ω rad/s. The result is exact for a balanced 3-phase, single pole-pair system.

For a p-pole-pair system (6-coil = 2 pole pairs, 12-coil = 4 pole pairs, as Drew describes for U-V-W-U-V-W and extended series topologies), the rotating field has p field maxima per revolution, and the electrical angular velocity ω_e relates to mechanical angular velocity ω_m as:
```
ω_e = p · ω_m
```

### Skin Depth in Ionized Argon Plasma at 500 kHz

The electromagnetic skin depth in a conductor:

```
δ = √(2 / (μ₀ σ ω))        [m]
```

where:
- μ₀ = 4π × 10⁻⁷ H/m (permeability of free space)
- σ = plasma electrical conductivity [S/m]
- ω = 2π × 500 × 10³ = π × 10⁶ rad/s

For weakly ionized argon at atmospheric pressure, σ_plasma ~ 10² – 10⁴ S/m (depending on ionization fraction). At σ = 10³ S/m:

```
δ = √(2 / (4π × 10⁻⁷ × 10³ × π × 10⁶))
  = √(2 / (4π² × 10²))
  = √(2 / (3948))
  ≈ √(5.07 × 10⁻⁴)
  ≈ 0.0225 m  = 2.25 cm
```

At σ = 10⁴ S/m (higher ionization fraction):
```
δ = 0.0225/√10 ≈ 7.1 mm
```

The skin depth decreases with increasing frequency and conductivity, concentrating induced currents near the plasma surface. At 500 kHz, the skin depth is of order 1–22 mm for the range of plasma conductivities cited — meaning the Lenz repulsion force is highly localized at the plasma boundary, which is the mechanism for efficient thrust coupling.

### Lenz Repulsion Force on Plasma Skin Layer

Induced EMF in plasma loop of area A at frequency ω:
```
ε = −dΦ/dt = −A B₀ ω cos(ωt)        [V]
```

Induced current (quasi-static, small plasma loop resistance R_plasma):
```
I_induced = ε / R_plasma = −(A B₀ ω / R_plasma) cos(ωt)        [A]
```

Repulsive force on plasma (time-averaged):
```
⟨F⟩ = ⟨I_induced × B⟩ · A = (A B₀ ω)² / (2 R_plasma)  [N]   (RMS average)
```

Force scales as ω² — this explains the frequency threshold behavior noted by Drew: no observable effect at low frequencies (small ω), strong repulsion at 500 kHz (large ω).

### Angular Momentum Balance — Counter-Spin Design for Zero Net L

**Spinning magnet (inner element):**
```
L_in = I_in · ω_in        [kg·m²/s]   (upward spin direction, +ẑ)
```

**Counter-rotating element (outer flywheel or channel):**
```
L_out = I_out · ω_out      [kg·m²/s]   (downward spin direction, −ẑ)
```

Design condition for zero net angular momentum:
```
L_net = L_in + L_out = I_in · ω_in − I_out · ω_out = 0
→  I_in · ω_in = I_out · ω_out
→  ω_out / ω_in = I_in / I_out
```

For equal moments of inertia (I_in = I_out):
```
ω_out = ω_in
```
Both elements must spin at equal rates in opposite directions. For unequal inertias:
```
ω_out = (I_in / I_out) · ω_in
```

**Newton's 3rd Law reaction force:**
If L_net = 0, there is no net angular momentum change, so no angular reaction torque is transmitted to the environment. However, the upward linear force F_up still has a Newtonian reaction F_down. Drew's claim is that the counter-spin eliminates this reaction — this is not physically justified by Newton's 3rd Law for linear forces, only for angular forces. The claim that counter-spin eliminates F_down is the key speculative step: either (a) the lift mechanism is gyroscopic/angular in nature (so L_net = 0 does eliminate it), or (b) there is a non-Newtonian coupling between angular and linear momentum that Drew's device is claimed to exploit.

### Focal-Point Magnetism — Axial Field of a Toroidal Source

For a toroidal coil of N turns, minor radius a, major radius R, carrying current I, the on-axis (Z-axis) magnetic field at height z above the torus center:

For the thin-torus approximation (a << R), the on-axis field approaches the sum of N circular loop contributions:
```
B_z(z) ≈ N · (μ₀ I R²) / (2(R² + z²)^(3/2))        [T]
```

Maximum on-axis field (at z = 0):
```
B_z,max = N μ₀ I / (2R)        [T]
```

The "focal point" in Drew's terminology is the z = 0 plane where B_z is maximum. The gradient of B_z along z:
```
dB_z/dz = −3N μ₀ I R² z / (2(R² + z²)^(5/2))        [T/m]
```

This gradient is zero at z = 0 and maximum at z = R/√2. A paramagnetic or conducting object placed near z = 0 experiences a force:
```
F_z = V_obj χ / μ₀ · (dB²/dz) / 2 = V_obj χ B_z · (dB_z/dz) / μ₀        [N]
```

For a diamagnetic object (χ < 0), the force is repulsive from the field maximum, toward the field minimum — this is the basis for diamagnetic levitation above a focal-point magnetic source. Drew's "focal-point magnetism" experiments appear to be exploring whether a toroidal or ring magnetic source can produce sufficient axial field gradient to generate measurable force on test objects.
