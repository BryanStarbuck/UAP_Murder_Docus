* HASER MODEL COMA PROFILE:

    * Column density: N(ρ) ∝ ∫ n(r) ds where ρ = impact parameter, integration along line of sight
    * For n(r) ∝ 1/r²: N(ρ) ∝ 1/ρ (the Haser model intensity decreases as 1/r from nucleus)
    * For n(r) ∝ exp(-r/r₀)/r² (Gaussian envelope): more rapidly decreasing outward

* ASYMMETRIC COMA PHYSICS:
  * If the coma is asymmetric due to solar radiation pressure:
    * Dust grain equation of motion: m_grain (d²r/dt²) = -GM_sun r̂/r² + F_rad r̂ where F_rad = L_sun σ_geo Q_pr / (4πr²c)
    * For micron-sized grains: F_rad/F_grav = β ≈ 0.1-1 (significant radiation pressure)
    * The grains drift anti-sunward with velocity v_drift = β v_esc (where v_esc = √(2GM_sun/r))
    * This creates the characteristic dust tail (anti-sunward) + ion tail (anti-sunward along B-field)
