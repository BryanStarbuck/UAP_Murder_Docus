PHYSICS / INFORMATION CONCEPTS:
* CRABWOOD BINARY DISC — DECODING METHODOLOGY (VISUALIZED):
  * This image is a working decoding diagram overlaid on the aerial photograph
  * It documents the methodology used by Paul Vigay (UK researcher, 2002) to decode the Crabwood binary message:
    1. Identify the spiral track structure in the disc formation
    2. Read each arc-segment as a binary bit: flattened = 1, standing = 0 (or vice versa)
    3. Group 8 consecutive bits into ASCII characters (8-bit ASCII encoding)
    4. Start marker: a specific bit pattern indicates the beginning of the message
    5. Read in spiral order from outside inward (or inside outward — direction determined by the start marker location)
  * The decoded characters visible ("T", "E", "r", "a", "B", "e", "w", "e") are consistent with the known Crabwood message: "Beware the bearers of FALSE gifts..."
  * "Beware" → B-e-a-r-e → these letters appear to be labeled on the spiral track
* ASCII ENCODING DETAILS:
  * 8-bit ASCII: each character = 8 bits
  * Example: "B" = 01000010 (visible in the inner spiral with "0010" shown and the "B" label)
  * The 1679 total bits / 8 bits per character = 209 character positions (not all used for message — some are padding/start-stop markers)
  * The spiral structure: reading from outside inward, each concentric ring = one revolution of the spiral track; each revolution contains multiple arc-segments (the bits)
  * Number of bits per revolution: if the disc has radius R and each bit subtends angle Δθ, then bits per revolution = 2π/Δθ
  * For the Crabwood disc: approximately 8 rings × ~26-27 bits per ring ≈ 210 bits per ring/row combination; total ≈ 1679 bits
* SPIRAL READING ORDER PHYSICS:
  * The reading direction (inward vs. outward) is determined by the position of the "start" marker
  * In a CD-ROM: data is read from inside outward at constant angular velocity (CAV) or constant linear velocity (CLV)
  * In the Crabwood disc: the spiral could be read in either direction; Vigay identified the start by finding a recognizable ASCII pattern (the initial "B" of "Beware" or specific start delimiter)
  * A red arrow in the image shows the reading direction — indicating the data flows inward (from outer ring to inner)
* INFORMATION RATE:
  * The Crabwood formation spiral: approximately 150-200 ASCII characters in the message
  * Total arc length of spiral: if each bit cell is ~0.75m × 0.75m and there are 1679 bits: total line length ≈ 1679 × 0.75m = 1259m ≈ 1.26 km of spiral track in a ~30m diameter circle
  * Number of revolutions: 1259m / (π × average_diameter) ≈ 1259/(π×15) ≈ 26-27 revolutions
  * This is consistent with the visible concentric ring count in the aerial photographs (~20-25 rings visible)
* DECODING AS A CRYPTANALYTIC PROBLEM:
  * Without knowing the encoding scheme, decoding the Crabwood disc is equivalent to:
    1. Identify the track structure (spiral vs. rings, direction, start)
    2. Identify the bit encoding (which segment state = 0, which = 1)
    3. Identify the character encoding (how many bits per character, what encoding table)
    4. Find the start delimiter
  * The 8-bit ASCII hypothesis was suggested by the factorization 1679 = 23×73 (same as the Arecibo message) and the recognizable English text output
  * If a different bit-per-character (7, 16, etc.) or encoding (EBCDIC, Unicode, etc.) were used, the message would be unreadable — ASCII was the correct choice
